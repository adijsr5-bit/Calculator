# ValuePilot — Free Financial Calculators & Money Planning Tools

ValuePilot is a high-precision, bank-grade personal finance application and suite of financial calculators built to empower users with mortgage planning, debt elimination strategies, budget tracking, tax refund estimation, and long-term retirement projections.

## 🚀 Key Features

- **Mortgage & Refinance Calculators**: Calculate monthly principal & interest payments, taxes, home insurance, HOA fees, PMI, and full 30-year annual amortization tables.
- **Debt Payoff Planner**: Avalanche & Snowball debt elimination modeling with dynamic interactive debt cards.
- **Car Loan Calculator**: Auto loan payment calculations with customizable terms, trade-in values, and interest rates.
- **50/30/20 Budget Planner**: Income allocation breakdowns into Needs (50%), Wants (30%), and Wealth Goals (20%).
- **Retirement & 401(k) Match Calculators**: Forecast compound growth, employer match money, and Roth/Traditional IRA retirement projections.
- **Tax Refund & Net Worth Tools**: Federal tax bracket estimates and private asset-liability tracking.
- **50 Financial Blog Guides**: SEO-optimized financial literacy guides covering credit scores, real estate, and wealth accumulation.
- **Pro Executive PDF Export**: Download 1-page financial statements with zero text clipping and executive header banners.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router, Server-Side Metadata, Static Site Generation)
- **Styling**: TailwindCSS, Glassmorphic UI design system, custom CSS rules
- **Icons & Charts**: Lucide React, Recharts
- **PDF Generation**: jsPDF, html2canvas (custom DOM cloning engine)

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
npm run build
```
